# SkyCast

A fast, installable weather forecast PWA built with React, TypeScript and Vite on the free [Open-Meteo](https://open-meteo.com/) API.

## Features (planned v1)
- Current conditions, hourly (24h) and 7-day forecast
- "My location" via browser geolocation
- City search (Open-Meteo Geocoding) and favourite cities (stored locally)
- °C/°F, km/h/mph unit toggles
- Installable and offline-capable (last forecast cached)

## Stack
React 18 · TypeScript (strict) · Vite · Vitest · Playwright · vite-plugin-pwa · GitHub Actions → GitHub Pages

## Data attribution
Weather data by [Open-Meteo.com](https://open-meteo.com/) (CC BY 4.0). Free for non-commercial use.
